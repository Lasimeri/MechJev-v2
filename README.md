# MechJev-v2

The XKEYSCORE portion of Mechanical Jev and Intel Phi Jev (the decision
engine, `xks`) rewritten in C, with a language learner beside it that
acquires words from its interactions with that engine. The Rust front end
is Mechanical Jev's TUI, reused as the harness.

Work in progress: see docs/plan.md.
